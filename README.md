# odin-recipes
My first HTML project!

# About the Project

This is a simple recipe website created as part of the Odin Project's Foundations course.

The website features three traditional Italian recipes, each with its own page containing description, list of ingredients, and cooking instructions.
Although this may seem simple and nothing special to experienced developers, it's a big milestone for me as someone who's just starting to learn coding.


## What I Learned

Through this project, i practiced building a multi-page website using HTML, organizing content, adding images, using Git and GitHub, and linking pages together.
